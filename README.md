### Products in production

- [**Corporate Documentation Hub**](https://github.com/Argus): multi-tenant platform for technical manuals and API catalogs, with per-version reading confirmation, RBAC, audit trail, PDF reports and e-mail notifications. React 19, TypeScript, Vite, Tailwind, Node/Express.
- [**BarberFlow**](https://github.com/jpmoraes2/BarberFlow): management, online booking and finance for barbershops. Clients book through a public link and pay a deposit through Pix, Brazil's instant payment system, to reduce no-shows (QR code or Pix Copia e Cola, EMV-compliant). Also includes a subscription club, cash flow, commissions, inventory, coupons and WhatsApp campaigns, with four access roles. React 19, TypeScript, Vite, Tailwind.
- [**DuoFinn**](https://github.com/jpmoraes2/DuoFinn): personal and couples finance, with no bank passwords or Open Finance. Forecasts the monthly balance, splits household bills (50/50 or proportional), settles via Pix, projects credit card installments and imports statements from CSV. Money math is cent-accurate, and each partner has privacy filters. React 19, TypeScript, Vite, Tailwind.
